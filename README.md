# Cootels Hotel Website

##  Дар бораи лоиҳа

Ин лоиҳа як веб-сайти муосири меҳмонхона бо номи **Cootels** мебошад, ки бо истифода аз HTML ва Tailwind сохта шудааст. Сайт барои муаррифии коттеҷҳо, хизматрасониҳо ва имкониятҳои истироҳат тарҳрезӣ шудааст.

##  Имкониятҳо

- Навигатсияи оддӣ ва фаҳмо
- Дизайни замонавӣ ва ҷолиб
- Бахши муаррифии меҳмонхона
- Маълумот дар бораи фаъолиятҳо ва хизматрасониҳо
- Намоиши намудҳои гуногуни ҳуҷраҳо
- Бахши саволҳои зиёд додашаванда (FAQ)
- Назарҳои мизоҷон (Testimonials)

##  Технологияҳои истифодашуда

- HTML5
- Tailwind
- Flexbox

##  Ҳадафи лоиҳа

Ҳадафи ин лоиҳа такмил додани малакаҳои HTML, Tailwind, ва сохтани интерфейси муосири веб мебошад.
